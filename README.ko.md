# flockswitch (Windows)

[English](README.md) · **한국어**

마우스 버튼 한 번으로 Logitech 마우스와 **키보드를 함께** 다른 컴퓨터로 넘깁니다.

flockswitch는 MX Master 마우스의 **휠 모드 전환 버튼, 제스처 버튼, 휠 클릭(휠을 눌러 클릭)** 중 고른 버튼을 Easy-Switch 버튼으로 바꿉니다. 누르면 그룹으로 묶은 장치(키보드, 다른 마우스)가 먼저, 마우스가 마지막으로 **같은 Easy-Switch 채널**로 이동합니다. 컴퓨터끼리 네트워크 연결이 필요 없어서 Logitech Flow를 쓸 수 없는 곳(공용 네트워크, 보안이 엄격한 네트워크)에서도 동작합니다.

이 저장소는 Windows 버전이며, [Microsoft Store](https://apps.microsoft.com/detail/9NN9ZLHLGSKN)에도 올라가 있습니다. 다른 버전은 [flockswitch-mac](https://github.com/WWhaleFe/flockswitch-mac), [flockswitch-linux](https://github.com/WWhaleFe/flockswitch-linux), [flockswitch-android](https://github.com/WWhaleFe/flockswitch-android)에 있으며, 모두 같은 방식으로 전환되어 섞어 쓸 수 있습니다.

> Logitech과 관계없는 개인 오픈소스입니다. "Logitech", "MX Master", "Easy-Switch", "Bolt", "Unifying"은 Logitech의 상표입니다.

## 필요한 것

- Windows 10 또는 11
- 휠 모드 전환 버튼·제스처 버튼·휠 클릭이 있는 Logitech MX Master 마우스 (Logi Bolt 수신기, Unifying 수신기 또는 블루투스 연결)
- 선택: 같은 채널로 페어링한 Logitech 키보드나 다른 장치
- Logi Options+ (함께 쓰는 것을 전제로 함)

## 지원 마우스

flockswitch는 **MX Master 3**와 **MX Master 4**를 바탕으로 만들고 시험했습니다. 같은 버튼과 기능(HID++ 2.0 *Change Host*, 버튼 재지정)을 가진 다른 Logitech 마우스도 동작할 수 있지만 **아직 시험하지 않았으며**, 추후 시험이 필요합니다. 다른 마우스에서 써 본 결과를 알려 주시면 반영하겠습니다.

## 준비

1. 키보드와 마우스를 각 컴퓨터에 **같은 채널 번호**로 페어링해 둡니다. 예: 채널 1 = 윈도우 PC, 채널 2 = 맥.
2. 오가는 **모든 컴퓨터에 flockswitch를 설치**합니다(맥에는 flockswitch-mac).
3. 설정하기 전에 Options+에서 사용할 버튼을 **동작 없음**으로 바꿔 두세요. 다른 기능이 할당돼 있으면 그 기능과 전환이 동시에 일어납니다.

## 설치

[Releases](../../releases)에서 내려받습니다.

### 설치형

1. `flockswitch-setup-<버전>.exe` 실행 → 설치 → 마치면 flockswitch가 시작되고 작업 표시줄 오른쪽 알림 영역에 ⇄ 아이콘
2. 현재 사용자에게만 설치되므로 **관리자 권한이 필요 없습니다** (`%LOCALAPPDATA%\Programs\flockswitch`). 시작 메뉴에 flockswitch / flockswitch Settings가 생기고, **설정 → 앱**에서 제거할 수 있습니다. 새 버전은 그대로 덮어 설치하면 됩니다(설정 유지).

### 포터블

1. `flockswitch-windows-portable-<버전>.zip`을 오래 둘 폴더(예: `문서\flockswitch`)에 압축 해제
2. `flockswitch.exe` 실행 → 작업 표시줄 오른쪽 알림 영역에 ⇄ 아이콘

파란 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누르세요. 새 버전은 앱이 스스로 확인하고 설치합니다(**설정 → 일반 → 업데이트**, 아래 참고).

## 사용

⇄ 아이콘 메뉴에서 상태 확인, 켜기/끄기, **설정…**, 종료를 할 수 있습니다. **설정…**을 누르면 설정 창이 열리고, 체크하는 즉시 적용되며 창은 열린 채로 유지됩니다.

| 탭 | 항목 | 내용 |
|---|---|---|
| 전환 | 마우스 버튼으로 전환 | 켜기/끄기 (끄면 버튼이 원래대로 동작) |
| 전환 | 버튼별 설정 | 휠 모드 전환·제스처·휠 클릭을 각각 켜기/끄기 (여러 개 가능) |
| 전환 | 이동할 채널 (버튼별) | 누르면 고른 채널 하나로 이동. 설정은 컴퓨터마다 따로라 각 컴퓨터에서 고르며, 이 컴퓨터의 채널은 고를 수 없음 |
| 전환 | 제스처 버튼 | 누르기와 누른 채 ↑↓←→ 움직이기, 다섯 가지에 각각 채널 지정 (방향을 켜면 누르는 동안 커서가 멈춤) |
| 전환 | 단축키 | 채널마다 키보드 단축키 하나(기본 Ctrl+Alt+1 / 2 / 3, 바꾸기 가능). 어떤 키보드로 눌러도 그룹 장치와 마스터 마우스가 그 채널로 이동. 제목 옆 ⓘ에 Windows에서 쓸 수 있는 조합(Ctrl이나 Alt에 Shift는 선택, 글자·숫자 하나 / F키)과 쓸 수 없는 조합(Windows 키 조합, 다른 앱이 등록한 조합)이 나옴. 이 PC에 연결된 장치만 움직일 수 있어서, 함께 넘어가지 않는 키보드(유선 등)로는 보내기만 되고 데려오기는 다른 컴퓨터에서 해야 함. 관리자 권한 불필요 |
| 전환 | 모서리 | 커서를 화면 바깥쪽 가장자리에 대고 잠시(0.3~2초, 선택) 머물면 그 방향에 정한 채널로 그룹 장치와 마스터 마우스가 이동. 네트워크 없이 각 컴퓨터가 자기 화면만 보므로 컴퓨터마다 켜고 각 방향에 그쪽에 있는 컴퓨터의 채널을 지정. 기다리는 동안 커서 근처에 효과(링·반원·막대·펄스·레이저·보텍스·스캔·리퀴드·랜덤 중 선택)가 줄어듦. 효과마다 색·크기를, 링·반원·막대는 줄어드는 방향을(링·반원은 작아지며 사라지기도) 따로 저장하고, 랜덤은 매번 효과와 함께 방향·사라지기도 무작위로 고름. Ctrl을 누른 동안에만 전환하는 옵션도 있음. 마우스가 돌아오면 커서가 보냈던 쪽 가장자리에 나타남. 네 귀퉁이는 제외되고, 모니터가 여러 대면 다른 모니터로 이어지는 가장자리는 전환하지 않음 |
| 장치 | 마스터 마우스 | 버튼을 쓸 마우스 |
| 장치 | 함께 이동할 장치 | Bolt·Unifying·블루투스 장치를 섞어서 선택. 다른 컴퓨터에 가 있는 장치도 표시 |
| 일반 | 진동 (진동 모터가 있는 마우스, 현재 MX Master 4) | 요약과 **진동 설정…** 창: 켜기/끄기, 세기, 떠날 때·돌아왔을 때 진동(종류 또는 랜덤), 모서리에서 점점 강하게/일정하게, **진동 확인** |
| 일반 | 마우스 찾기 | 단축키, 다른 컴퓨터에서 도착, 마우스 흔들기로 커서 주변에 펄스 링·레이더·스포트라이트·랜덤 효과를 고른 색과 크기로 표시. 흔들기는 흔드는 시간(0.5~2초)과 함께 누를 키(없음·Ctrl·Alt·Shift)를 고를 수 있음 |
| 일반 | 업데이트 | 현재 버전, **지금 확인**(새 버전이 있으면 **지금 업데이트**로 바로 설치), 릴리스(Store 버전은 Store) 페이지. **자동으로 새 버전 확인**(시작할 때와 하루에 한 번)과 **새 버전 자동 설치**를 각각 켜고 끌 수 있음. Store 버전은 Microsoft Store에서 받아 백그라운드로 설치하고, GitHub 버전은 받은 파일을 릴리스의 SHA256SUMS.txt로 확인한 뒤 설치형은 설치 프로그램을 조용히 실행하고 포터블은 실행 파일을 바꿉니다. 설치 중 flockswitch가 잠시 닫혔다가 다시 켜짐. 트레이 메뉴에도 새 버전 설치 항목이 나타남 |
| 일반 | 설정 백업 | **저장**: 지금 설정을 문서\flockswitch 폴더에 .toml 파일로 저장(최대 10개, 개수 표시). **불러오기…**: 그 폴더의 파일을 골라 확인을 거쳐 불러옴. **관리…**: 파일 이름 바꾸기·삭제(휴지통으로). **폴더 열기**: 탐색기로 폴더를 열어 다른 컴퓨터와 파일을 주고받음. macOS·Linux 버전에서 저장한 파일도 불러올 수 있음. 채널은 컴퓨터마다 따로라 다른 컴퓨터에서 불러온 뒤 확인 필요 |
| 일반 | 초기화 | 언어를 뺀 모든 설정을 처음 상태로 되돌리기 |
| 일반 | 시작하기 전에 | Options+에서 사용할 버튼을 "동작 없음"으로 바꾸라는 안내 |
| 일반 | 언어 | 한국어 / English (처음에는 컴퓨터 언어를 따름) |
| 일반 | 로그인 시 자동 실행 | 관리자 권한 없이 현재 사용자에게만 등록 |
| 일반 | 제거 | 버튼 원래대로, 자동 실행 해제, 설정 삭제 후 종료 |

명령줄: PowerShell에서 `flockswitch.exe help`

설정 위치: `%APPDATA%\flockswitch\`

## 제거

1. ⇄ 메뉴 → **설정…** → 맨 아래 **flockswitch 제거…** → **제거**. 버튼을 원래대로 돌려놓고, 자동 실행을 해제하고, 설정 폴더를 지운 뒤 종료합니다.
2. 설치형은 **설정 → 앱**에서 제거, 포터블은 폴더를 지웁니다.

드라이버나 서비스를 설치하지 않고 시스템 설정도 바꾸지 않습니다.

## 개인정보

flockswitch는 이 PC에 연결된 Logitech 장치와만 통신합니다. 인터넷 연결은 새 버전 확인과 내려받기뿐이며(끌 수 있음), 사용자에 관한 정보는 보내지 않습니다. (중복 실행을 막으려고 `127.0.0.1`의 포트 하나를 잡아 둘 뿐, 그 포트로 주고받는 데이터는 없습니다.) 전문: [개인정보처리방침](PRIVACY.md#개인정보처리방침--flockswitch-windows).
